# 蒙特卡洛方法：无偏估计及优缺点解析

---

### 一、蒙特卡洛方法（Monte Carlo, MC）详细解析

在强化学习中，MC是一类**无模型（Model-Free）的价值估计方法，核心是通过完整回合采样**来估计状态/动作价值，不依赖环境的先验模型（如状态转移概率、奖励函数）。

#### 1. 核心思想

MC的本质是**“用经验平均代替期望”**：

- 不预先知道环境如何变化（不需要  $P(s'|s,a)$ 、 $R(s,a,s')$ ），而是通过和环境交互，**完整跑完多个回合（Episode）**（从起始状态到终止状态的完整序列）。

- 对每个状态  $s$ ，记录所有访问  $s$  后到回合结束的**实际累积回报 ** $G_t$ ，再用这些  $G_t$  的平均值来估计状态价值  $V(s)$ 。

#### 2. 关键分类

- **首次访问MC（First-Visit MC）**：每个回合中，仅在**第一次**访问状态  $s$  时记录对应的  $G_t$ ，用于后续平均。

- **每次访问MC（Every-Visit MC）**：每个回合中，**每次**访问状态  $s$  都记录对应的  $G_t$ ，用于后续平均。

#### 3. 典型流程

1. **采样完整回合**：遵循策略  $\pi$ ，与环境交互生成多个完整回合，记录序列  $\{S_0, A_0, R_1, S_1, A_1, R_2, ..., S_T\}$ 。

2. **计算累积回报**：对每个时刻  $t$ ，计算从  $t$  到回合结束的累积回报  $G_t = R_{t+1} + \gamma R_{t+2} + ... + \gamma^{T-t-1} R_T$ （ $\gamma$  为折扣因子）。

3. **估计状态价值**：对状态  $s$ ，收集所有访问  $s$  时的  $G_t$ ，计算样本均值  $\bar{G}(s) = \frac{1}{N}\sum_{i=1}^N G_t^{(i)}$ ，作为  $V^\pi(s)$  的估计。

4. **增量式更新**：为避免存储所有样本，用增量公式迭代更新：

 $V(S_t) \leftarrow V(S_t) + \alpha \left[ G_t - V(S_t) \right]$ 

其中  $\alpha$ 是学习率， $G_t$  是当前回合中  $S_t$  对应的实际累积回报。

#### 4. 核心特点总结

|特点|解释|
|---|---|
|✅ 无模型|无需预先知道环境的状态转移概率和奖励函数，直接通过交互采样学习。|
|✅ 无偏估计|估计值的期望等于真实状态价值，无系统性偏差（下文详细展开）。|
|❌ 高方差|每个  $G_t$  是从  $t$  到结束的所有奖励之和，受后续多步随机因素影响，样本波动大。|
|❌ 回合级更新|必须等完整回合结束才能计算  $G_t$ ，无法像时序差分（TD）那样每步即时更新，不支持在线学习。|

### 二、为什么MC是无偏估计？“无偏”如何理解？

#### 1. 统计学定义：无偏估计

若一个估计量  $\hat{\theta}$  的**期望等于真实参数 ** $\theta$ ，即：

 $E\left[ \hat{\theta} \right] = \theta$ 

则称  $\hat{\theta}$  是  $\theta$  的**无偏估计量**。

#### 2. MC无偏性的数学证明

状态价值函数的定义是：

 $V^\pi(s) = \mathbb{E}_\pi \left[ G_t \mid S_t = s \right]$ 

即：在状态  $s$  下，遵循策略  $\pi$  的后续累积回报  $G_t$  的**期望**，就是状态  $s$  的真实价值。

MC用**实际采样的 ** $G_t$  作为  $V^\pi(S_t)$  的估计：

- 对单个样本  $G_t$ ： $E\left[ G_t \mid S_t = s \right] = V^\pi(s)$ （直接由定义得出）。

- 对样本均值  $\bar{G}(s) = \frac{1}{N}\sum_{i=1}^N G_t^{(i)}$ ：

 $E\left[ \bar{G}(s) \right] = \frac{1}{N}\sum_{i=1}^N E\left[ G_t^{(i)} \mid S_t = s \right] = \frac{1}{N} \cdot N V^\pi(s) = V^\pi(s)$ 

因此，无论是用单个  $G_t$  还是样本均值  $\bar{G}(s)$  估计  $V^\pi(s)$ ，**估计量的期望都等于真实价值**，所以MC是无偏估计。

#### 3. “无偏”的直观理解

- **不会系统性高估/低估**：多次采样后，MC估计值的平均值会收敛到真实状态价值，没有“偏向”某一边（比如不会一直估高或一直估低）。

- **对比有偏估计**：时序差分（TD）方法用  $R_{t+1} + \gamma V(S_{t+1})$  估计  $V(S_t)$ ，若  $V(S_{t+1})$  本身是估计值（非真实值），则这个估计量的期望不等于真实  $V^\pi(S_t)$ ，属于**有偏估计**；而MC的  $G_t$  是真实累积回报，直接对齐价值函数的定义，因此无偏。

- **注意**：无偏 ≠ 准确。单个MC样本的波动极大（方差高），但**长期平均来看是对的**，这就是“无偏”的核心含义。

### 三、MC的优缺点总结

|优点|缺点|
|---|---|
|无模型，适配复杂环境|必须等回合结束，无法在线学习|
|无偏估计，理论上收敛到真实价值|高方差，样本波动大，学习效率低|
|实现简单，无需推导环境模型|对长回合问题， $G_t$  的计算成本高|
